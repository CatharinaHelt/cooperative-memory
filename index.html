Cooperative Memory

Catharina Helten, Patrick Wolf

Overview

This website provides supplementary material for our paper on memory-aware environmental knowledge sharing in cooperative autonomous robot systems.

System

Each robot maintains a short-term memory and a long-term environmental representation. Knowledge can be transferred between robots to make relevant information available before it enters the receiving robot's sensor range.

Experiments

  • Single robot: STM compared with STM and LTM
  • Two robots: information sharing compared with no sharing
  • Occluded and out-of-range environmental elements
  • Playback-based receiver evaluation
