The problem

Current perception is local. Useful knowledge should not be.

A robot can miss an obstacle because of occlusion, noise, or a temporary sensor failure. At the same time, a previously observed obstacle may have genuinely been removed. The memory must therefore remain stable under short-lived errors while adapting to persistent environmental change.

This website collects the system overview, experimental protocol, quantitative results, and implementation material for the paper.
