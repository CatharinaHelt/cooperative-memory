# Cooperative Memory supplementary website

This is a framework-free GitHub Pages template. Upload the contents of this
folder to the repository that serves `catharinahelt.github.io/cooperative-memory/`.

## Files

- `index.html` — overview, system explanation, experiments, and citation
- `results.html` — result panels and metric table ready for final values
- `styles.css` — responsive visual design; no build step required
- `assets/` — reserved for figures, paper PDF, video, and robot photos

## Before publication

1. Replace the placeholder BibTeX entry with the final citation.
2. Replace the source-code URL if the repository name changes.
3. Add the paper PDF and final figures to `assets/`.
4. Replace the video placeholder with a real `<video controls>` element when
   `assets/demo.mp4` is available.
5. Replace the dashes in `results.html` with aggregated values and confidence
   intervals.
6. Update the author contact address if necessary.

The template intentionally does not claim behavior adaptation: the site and
paper focus on constructing, sharing, and revising environmental memory.
